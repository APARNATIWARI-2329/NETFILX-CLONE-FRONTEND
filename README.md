# 🎬 Netflix Clone

A responsive Netflix-inspired landing page built using HTML and CSS. This project recreates the look and feel of Netflix's homepage while focusing on responsive design, modern UI components, and clean frontend development practices.

---

## 🚀 Features

* Responsive Netflix-style landing page
* Modern hero section with call-to-action
* Responsive navigation bar
* Media showcase sections
* Interactive FAQ section
* Mobile-friendly design
* Clean and organized UI

---

## 🛠️ Technologies Used

* HTML5

* Flexbox
* Responsive Design
* Media Queries
